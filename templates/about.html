About the project

PlantCare AI

An AI-based plant leaf disease detection application, built as an academic project.

Project objective

To help farmers, gardeners and students detect plant leaf diseases early by photographing a leaf. The application identifies the plant, decides whether the leaf is healthy or diseased, names the disease, and gives symptoms, treatment and prevention advice.

How the application works

  1. The browser sends the leaf photo to the Flask server through POST /api/predict.
  2. The server checks the file is a real JPG or PNG under {{ max_mb }} MB.
  3. A quick colour check makes sure the photo actually contains a leaf.
  4. The image is resized to {{ image_size }} × {{ image_size }} pixels, the size the model was trained on.
  5. The trained neural network outputs a probability for each of its classes.
  6. The most likely class is mapped to the plant, disease and its care information.
  7. If the top probability is below {{ threshold }}%, the app reports "uncertain" instead of guessing.
  8. The result is saved to the SQLite database and shown on the result page.

AI-based plant disease detection

PlantCare AI uses a convolutional neural network (CNN). CNNs learn to recognise visual patterns such as spot shapes, colours, rings and textures directly from example images. The model is MobileNetV2, a compact network designed for phones. It was trained on labelled leaf photos from the PlantVillage dataset and from Indian crop datasets (MangoLeafBD for mango, rice and wheat field photos, and a Tulsi dataset from Maharashtra). It also learned an extra "other plant" class from leaves of species it does not support, so it can say when a photo is outside its knowledge.

The model is a classifier, not a general plant identifier: it can only choose between the plant and disease classes it was trained on. Leaves from other species may be reported as uncertain or, sometimes, matched to the most similar known class. A single leaf on a plain surface, in daylight, gives the most reliable result.
